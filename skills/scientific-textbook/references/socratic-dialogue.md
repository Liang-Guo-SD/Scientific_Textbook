# Socratic Collaboration

Use questions to improve decisions, not to transfer all reasoning back to the user.

## Ask only when the answer matters

Ask when different answers would materially change:

- the target learner or exit capability;
- curriculum architecture or prerequisites;
- evidence, source, experiment, or assessment requirements;
- safety, ethics, privacy, regulatory, or publication boundaries;
- an irreversible or expensive implementation choice.

Do not ask when the answer is discoverable from project files, safely reversible, or a minor stylistic preference covered by existing conventions.

## Use short rounds

Ask one to three questions at a time. For each question:

1. state the decision in plain language;
2. explain in one sentence what changes based on the answer;
3. offer a recommended default when appropriate;
4. allow the user to answer freely rather than forcing false precision.

Prefer questions that expose reasoning:

- “What should a successful reader be able to produce without assistance?”
- “Which claim in this chapter would be most damaging if it were wrong?”
- “What prior knowledge are we assuming that the weakest intended reader may not have?”
- “Which evidence would distinguish understanding from merely following instructions?”
- “Where should the book explicitly stop short of professional advice or operational action?”

Avoid asking users to invent a chapter count, template, or evidence system before the learning goal is clear.

## Classify uncertainty

- **Blocking:** guessing changes scope, safety, scientific claims, or publication intent. Pause and ask.
- **Provisional:** a reasonable default permits reversible progress. State the assumption, record it, and continue.
- **Cosmetic:** follow the style guide or choose a consistent default without interruption.

## Close each checkpoint

Summarize confirmed decisions, provisional assumptions, open questions, and the next action. Write them into `PRD.md`, `DECISIONS.md`, `PROGRESS.md`, or the target contract so a later session does not repeat the dialogue.

Socratic questioning remains available throughout the project. Re-open it when evidence contradicts an assumption, a chapter reveals a prerequisite gap, or release scope changes.
